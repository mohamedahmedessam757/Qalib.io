# Qalib

## Surface

**Product** — a personal daily work tool (not a marketing site).

## Audience

Single owner (Mohamed) editing Arabic/English Word documents for work. One authenticated role only.

## Job to be done

Upload a `.docx`, edit text/tables/regions in the browser with high OOXML fidelity, save to the cloud, download `.docx` or export PDF — without running a paid private server.

## Product lanes

- **Home** — brand + clear entry to documents or login
- **Login** — email/password (single user)
- **Documents** — list, upload, empty state, open editor
- **Editor** — full-height OOXML editor chrome; document content stays Word-native

## Voice

Calm, precise, work-ready. Short labels. Arabic-first with English parity. No hype copy.

## Anti-references

- Purple-to-indigo SaaS gradients
- Nested card grids / dashboard chrome for a simple tool
- Inter / Roboto / Arial as primary UI fonts
- Bounce / elastic motion
- Applying Qalib theme colors into the Word document canvas
